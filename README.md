## 🚀 Cara Menyambungkan ke GitHub (Sangat Cepat)

Ikuti 3 langkah mudah ini untuk mengunggah proyek Kakak:

1. **Buat Repositori di GitHub**
   - Buka [GitHub New Repo](https://github.com/new).
   - Beri nama repositori Anda (contoh: `abdi-pratama-os`).
   - Biarkan semua pilihan lainnya kosong (jangan centang README/Gitignore).

2. **Buka Terminal di Folder Ini**
   Salin dan tempel perintah berikut secara berurutan:
   ```bash
   git init
   git add .
   git commit -m "Launch: Abdi Pratama Sales OS v5.2"
   git branch -M main
   git remote add origin https://github.com/USERNAME_ANDA/NAMA_REPO_ANDA.git
   git push -u origin main
   ```
   *(Ganti **USERNAME_ANDA** dan **NAMA_REPO_ANDA** dengan data GitHub Kakak)*

3. **Aktifkan Firebase App Hosting**
   Setelah di-push, Kakak bisa masuk ke [Firebase Console](https://console.firebase.google.com/) dan hubungkan repositori GitHub tersebut untuk deploy otomatis secara gratis!

## Pengembangan
